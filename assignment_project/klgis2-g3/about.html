Project Title

Relational Analysis on Carbon Stock Estimation in Roadside Trees and Road Classification in Satok, Sarawak.

Client / Data Owner

North Kuching City Hall (DBKU), with urban tree and road data for Satok.

Institutional Context

SBEG 3542 GIS CAMP II (2025/2026), Faculty of Built Environment and Surveying, UTM.

Project Overview

This project delivers a web-based GIS dashboard to evaluate how roadside tree distribution supports urban carbon mitigation in Satok, Kuching. It combines spatial visualization, tree attributes, and carbon stock estimation to support data-driven landscape planning.

Objectives

  1. Develop an interactive web GIS platform for urban landscape and carbon absorption analysis.
  2. Compare tree distribution and density across roadside and residential settings.
  3. Provide map-based analytics to help authorities evaluate green landscape effectiveness as a carbon mitigation mechanism.

Study Area

The focus area is Satok, Kuching, Sarawak, a mixed-use urban zone with road networks, residential neighborhoods, commercial areas, and public facilities. The selected area supports practical smart-city style GIS monitoring for DBKU.

Problem Statement

Although DBKU has spatial data, conventional visualization approaches do not provide enough interactivity to analyze the combined effects of roadside trees, road hierarchy, and transport-related carbon emissions. This project addresses that gap through a user-friendly GIS dashboard with map, filter, and analysis capabilities.

Scope & Methodology

The analysis focuses on existing DBKU roadside tree and road datasets. The workflow applies cleaning, road classification, attribute structuring, and carbon estimation references to produce reliable insights.

01

Data Screening

Audit raw tree and road tables, fix missing values, and standardize naming for consistent querying.

02

Road Class Structuring

Normalize roads into Main, Secondary, and Tertiary hierarchy to align spatial comparison.

03

Carbon Computation

Apply AGB-based calculations using measured diameter attributes to estimate carbon indicators.

04

GIS Integration

Align layers with proper CRS, validate topology, and package results for web map display.

05

Dashboard Delivery

Serve outputs through interactive map layers, filters, and charts for evidence-based planning.

Data and GIS Workflow

  • Spatial layers used: Road and Tree; attribute tables include Tree Info.
  • Road classes standardized into Main, Secondary, and Tertiary categories.
  • Processing CRS: Timbalai 1948 / Borneo RSO; web visualization CRS: WGS84.
  • System output: interactive map views, filters, and chart-based summaries.

Collaboration Goal

The project translates technical GIS processing into a practical decision support interface. It helps stakeholders quickly read where urban tree systems are strong, where they are weak, and where interventions can improve carbon mitigation outcomes.
