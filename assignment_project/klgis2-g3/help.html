About the Dashboard

The Satok Area Tree Distribution Dashboard provides comprehensive visualization and analysis of urban tree distribution and carbon stock in the Satok area of Kuching, Sarawak. This tool helps urban planners, environmentalists, and city officials make data-driven decisions about urban forestry management.

Using Filters

The dashboard provides several filtering options to help you analyze specific tree data:

  • Tree Type: Filter by tree species (Mahogany, Angsana, Mimusops, etc.)
  • Road Type: Filter by location category (Roadside, Housing Area, Parks, Commercial)
  • Owner: Filter by tree ownership (DBKU, Others)
  • Location: Filter by specific street names
  • Minimum Diameter: Use the slider to filter trees by minimum diameter size

Charts will automatically update when you change any filter. To reset, select "All" for each dropdown and move the diameter slider to minimum.

Understanding the Charts

The dashboard displays four main visualizations:

  • Tree Distribution by Road Type: Bar chart showing total number of trees across different road classifications
  • Average CO₂ Absorption by Species: Pie chart displaying average carbon sequestration rates by tree species
  • Tree Distribution by Owner: Doughnut chart showing ownership distribution of trees
  • Tree Distribution by Location: Horizontal bar chart showing tree counts by street location

Carbon Calculation Methodology

CO₂ sequestration and carbon stock values are calculated using the Above Ground Biomass (AGB) formula:

AGBest = 0.0673 × (ρD2H)0.976
Where D is in cm, H is in m, and ρ is in g cm-3.

Carbon stock is then calculated from AGB, and CO₂ sequestration represents the annual carbon capture rate of each tree.

Interactive Map

The interactive map shows the geographical distribution of trees with the following features:

  • Tree Markers: Click on markers to view detailed tree information
  • Roads Layer: Toggle road network visibility
  • Orthophoto: Toggle aerial imagery for context
  • Opacity Control: Adjust transparency of map layers
  • Reset View: Return to default map extent

Data Source

All data is provided and maintained by Dewan Bandaraya Kuching Utara (DBKU). The database includes detailed information about each tree including species, location, size measurements, health status, and calculated carbon metrics.

Data is stored in a PostgreSQL database with PostGIS extension for spatial analysis capabilities.

Mobile Usage

This dashboard is fully responsive and optimized for mobile devices:

  • Navigation menu collapses into a hamburger menu on small screens
  • Charts automatically resize for optimal viewing
  • Filters stack vertically for easy access
  • Touch-friendly controls for map interaction

Frequently Asked Questions

Q: Why do some charts show "Unknown" values?

A: This indicates missing data in the database for certain trees. Contact DBKU to update incomplete records.

Q: Can I export the data?

A: Data export is managed by system administrators. Contact your administrator for custom export requests.

Q: How often is the data updated?

A: The database is updated regularly by DBKU field teams. Check the "Last Updated" date in the header for the most recent update.

Q: What browsers are supported?

A: The dashboard works best on modern browsers: Chrome, Firefox, Safari, and Edge (latest versions).
